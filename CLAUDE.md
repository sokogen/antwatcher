# antwatcher

The contributor instructions for this repository live in `AGENTS.md`: build, test
and lint commands, the package layout, the architecture rules enforced by
`internal/archtest`, the error and registration conventions, and the recipes for
adding a bus or a sink driver. They are agent-agnostic and kept current with the
code, so they are imported here rather than copied — a second copy would drift.
